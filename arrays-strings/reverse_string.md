# Reverse String

- **Problem:** Reverse String
- **Platform:** LeetCode
- **Problem Link:** https://leetcode.com/problems/reverse-string/

## Approach
I used two pointers, one at the beginning and one at the end of the string. I swapped the characters at these positions and moved the pointers towards the middle until the string was reversed.

## Time Complexity
O(n)

## Space Complexity
O(1)

## Test Case
- Input: hello
- Output: olleh
